Sequencial vs. paralelo,
mesma saída, menos tempo.

Um pipeline de processamento de imagens executado com um processo e com multiprocessing, comparando tempo, corretude (SHA-256) e speedup real frente à Lei de Amdahl.

Sequencial

Processa o dataset inteiro em um único processo (src/sequential.py), usado como linha de base de tempo.

Paralelo

Distribui as imagens entre um pool de processos (multiprocessing.Pool), com um Lock mínimo apenas para o contador de progresso e o relatório CSV compartilhados.

Uso

# instalar
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# gerar dataset sintético
python src/generate_dataset.py --count 1000 --output dataset

# rodar o benchmark (sequencial + N processos, com verificação SHA-256)
python src/benchmark.py --dataset dataset --workers 2 4 8
